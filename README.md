
# Libraries & Their Usage

This section explains the purpose of each installed library and how it will be used in this project.

| Library | Purpose in This Project |
|---|---|
| **React Router DOM** | Used to manage navigation between different pages without reloading the entire application. |
| **Axios** | Used to send HTTP requests and retrieve data from external APIs. |
| **Zustand** | Used to manage global application state and share data between components. |
| **Formik** | Used to manage form values, handle form submissions, and simplify form interactions. |
| **Yup** | Used to define validation schemas and validate user input in forms. |
| **Tailwind CSS** | Used to style the application and maintain a consistent design system through centralized design tokens. |
| **React Icons** | Used to integrate icons from different icon libraries into the application's user interface. |
| **Lucide React** | Used to provide clean, lightweight, and customizable icons for buttons, navigation, and other interface elements. |
